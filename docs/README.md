# Documentation

This folder contains version-controlled technical documentation for Stochastic Sketches.

Planned documents:

- `architecture.md` — plugin structure and shared design decisions.
- `palette.md` — Palette controls, algorithm, inputs, outputs, and behaviour.
- `drift.md` — Drift capture, playback, and mutation behaviour.
- `palette-link-protocol.md` — the Palette-to-Drift 12-channel CV protocol.
- `testing.md` — repeatable manual Rack test cases and results.
- `research-to-implementation.md` — links between research sources and project features.

Keep user-facing setup and patch instructions in the repository root `README.md`. Keep detailed implementation documentation here, updated alongside the relevant feature.
